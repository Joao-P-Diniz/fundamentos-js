Aprendendo Desenvolvimento Web

O desenvolvimento web é a área responsável pela criação de sites e aplicações que podem ser acessados por navegadores.

As principais tecnologias utilizadas no front-end são HTML, CSS e JavaScript, responsáveis pela estrutura, estilo e interatividade das páginas.

Com prática constante, criação de projetos e resolução de exercícios, é possível evoluir do nível iniciante até o profissional.

  • HTML - Estrutura das páginas
  • CSS - Estilização e layout
  • JavaScript - Interatividade
  • Git e GitHub - Controle de versão
